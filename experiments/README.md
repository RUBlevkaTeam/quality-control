# Простой EDA

В папке оставлен один самодостаточный ноутбук — `eda.ipynb`.

Он отвечает на базовые вопросы о данных:

1. сколько объектов и есть ли проблемы со схемой;
2. как распределены категории и метки;
3. какой объём текста и какие слова встречаются чаще;
4. сколько изображений есть у товаров и как выглядят примеры;
5. сколько в данных точных текстовых дублей.

Код рассчитан на дальнейшую самостоятельную доработку: одна небольшая задача
на ячейку, явные промежуточные переменные, короткие функции и комментарии перед
неочевидными действиями. Текстовые колонки обрабатываются векторизованными
операциями pandas `.str`; плотные цепочки и сложные абстракции намеренно не
используются.

Ноутбук дополнительно проверяет HTML в описаниях, длины названий и описаний
по отдельности, покрытие изображениями в разрезе `category × label`, размеры
групп дублей и примеры конфликтующих меток.

Ноутбук не обучает модели, не создаёт промежуточные артефакты и не меняет
исходные данные. Его можно запускать целиком из корня репозитория:

```bash
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=600 experiments/eda.ipynb
```

Зависимости: pandas, NumPy, Pillow, Matplotlib, Seaborn и scikit-learn.
